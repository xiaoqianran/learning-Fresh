# Fresh 实战学习

交互式中文 **Deno Fresh** 教程：课程 + 测验 + 进度 + 代码实验室 + 模拟全栈工坊。

**仓库：** https://github.com/xiaoqianran/learning-Fresh

---

## 这是什么

面向想系统学习 **Fresh**（Deno 全栈框架：默认零 JS、Islands 架构）的同学。

你可以：

- 按路径学完主修课程（讲解 + 源码 + 交互 Demo + 小测验）
- 在 **代码实验室** 浏览 routes / islands 示例
- 在 **全栈工坊** 练登录、401、笔记 CRUD（模拟 REST API）
- 用 **速查表 / 学习中心 / 错题本 / 结业证明** 跟进度

> 说明：本站用 React + TanStack Start 承载教学内容；示例源码为真实 Fresh / Preact 写法。

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认绑定 `0.0.0.0:8080`。

```bash
npm run build
npm run build:pages   # GitHub Pages
npm run typecheck
```

## 技术栈

- 界面：React 19、TanStack Start / Router、Vite、Tailwind v4
- 进度：Zustand
- 工坊：MSW 模拟 REST
- 部署：GitHub Actions → GitHub Pages / 或 Vercel

## 学习路径

基础 → 进阶 → 全栈准备 → 工坊闯关 → 工程化 → 进阶模式 → 官网补全
